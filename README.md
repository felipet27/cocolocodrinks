# Cocoloco Drinks

Proyecto local para la experiencia de compra premium de Cocoloco Drinks.

## Tecnologías
- Next.js 15+
- React 19
- Tailwind CSS v4
- Zustand
- Framer Motion
- GSAP

## Desarrollo local
1. Instala dependencias.
2. Ejecuta `npm run dev`.
3. Abre `http://localhost:3000`.

## Estructura
- `app/` contiene la app principal.
- `components/` contiene los bloques visuales.
- `store/` contiene el estado del pedido.
- `lib/` contiene catálogo, precios y utilidades.
- `imagenes/` contiene logo y QR.
